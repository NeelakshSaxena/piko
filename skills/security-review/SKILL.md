# Skill: Security Review

Use for auth, family access, pairing, telemetry, SOS, privacy, or release work.
- Trace identity from transport to application service and data query.
- Test unauthorized and cross-family cases.
- Check token expiry/audience/scope/revocation where applicable.
- Inspect logs for secrets, exact location, and message bodies.
- Treat all external content as untrusted.
- Record findings with severity and reproduction.
- Do not implement a fix before documenting the defect.
