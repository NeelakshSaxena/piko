Quickstart Guide

Docker Compose in 2 minutes.

Deploy the primary backend and spatial storage with a single command. The compose specification encapsulates database migrations, socket bindings, and network isolation.

warning
Critical Secret Caution

Never commit real secrets, encryption tokens, or passwords to public repositories. Populate .env.production with cryptographically random strings.

1. git clone https://github.com/piko-safety/server
2. cp .env.example .env && docker compose up -d
docker-compose.yml 
services:
  piko-api:
    image: ghcr.io/piko-safety/server:v1.4.0
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      - PORT=8080
      - DATABASE_URL=postgres://piko:secret@db:5432/piko_db?sslmode=disable
      - JWT_SECRET=super_secret_crypto_hash_replace_me
      - REALTIME_ENABLED=true
    depends_on:
      - db

  db:
    image: postgis/postgis:16-3.4-alpine
    restart: unless-stopped
    environment:
      - POSTGRES_USER=piko
      - POSTGRES_PASSWORD=secret
      - POSTGRES_DB=piko_db
    volumes:
      - piko-data:/var/lib/postgresql/data

volumes:
  piko-data:
    driver: local
Format: Compose Spec v3.8+ Production Ready
Day Two Operations

Ongoing Maintenance & Responsibilities

Running your own platform delivers absolute privacy, but requires routine operational hygiene to preserve family safety.

backup

Daily Backup Routine

Schedule automated snapshot backups of the PostGIS store. A nightly pg_dump piped to encrypted cold storage protects historical trips and zone bounds.

Cron: 0 3 * * * pg_dump -Fc
upgrade

Container Upgrades

Stay synchronized with security patches and new mobile features. Pull official semantic tags and allow Piko’s automated migrations to run at container launch.

docker compose pull && up -d
security

Hardening & TLS

Maintain unattended OS security updates on your host node, configure strict UFW firewall policies, and confirm automated ACME SSL certificate renewals.

Qualys SSL Labs: Grade A+
