# Skill: Phase Runner

Use when implementing a Piko phase.
1. Read AGENTS.md, STATE.md, and exactly one phase prompt.
2. Inspect current files and git status.
3. Define smallest plan and expected files.
4. Implement only phase scope.
5. Run exact verification commands.
6. Save evidence under docs/verification.
7. Update STATE.md only if exit gate is met.
8. Stop; never start the next phase automatically.
